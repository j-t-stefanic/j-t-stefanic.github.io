# 🏈 College Football Data Analytics
**Python · MySQL · SQL · Excel · ETL · Data Modeling**

## Project Overview
This project turns college-football roster data into structured datasets that can be explored with SQL and used for increasingly advanced reporting and analysis.

## Workflow
Roster Sources → Structured Excel Workbook → Python Data Preparation → MySQL Table Generation → SQL Analysis & Reporting

## Key Work
- Organized Division I roster information into an Excel workbook with team-specific worksheets.
- Converted spreadsheet data into MySQL-compatible CREATE TABLE and INSERT statements.
- Created separate team tables using recognizable team names.
- Built Python logic to connect to a local MySQL instance and load generated SQL.
- Developed SQL exercises around roster composition, positions, counts, height, weight, averages, minimums, maximums, and grouped reporting.

## Example Analytical Questions
- How many players are assigned to each position?
- Which position groups have the highest average weight?
- What are the lightest and heaviest players within each position group?
- How do roster characteristics vary across teams and positions?

## Skills Demonstrated
Python · SQL · MySQL · Excel · ETL · GROUP BY · Aggregations · Data Modeling · Reporting
