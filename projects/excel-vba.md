# 📊 Excel & VBA Automation
**Excel · VBA · Data Transformation · Workflow Automation**

## Project Overview
These projects demonstrate how VBA and spreadsheet logic can automate repetitive business processes, consolidate data, and improve consistency.

## Featured Example: Combine Sheets
The Combine_Sheets VBA workflow consolidates multiple worksheets into a single summary dataset.

## Automation Logic
- Determines workbook and worksheet structure dynamically.
- Copies column headers from the first worksheet only.
- Identifies the last populated row and column rather than relying on fixed ranges.
- Appends data from row 2 onward for subsequent worksheets.
- Consolidates multiple datasets into one reporting sheet.
- Reduces repetitive copy-and-paste work.

## Skills Demonstrated
Excel · VBA · Macros · Dynamic Ranges · Worksheet Automation · Data Consolidation · Data Transformation · Validation

## Business Value
A repeatable process reduces manual handling, makes transformations consistent, and lets Excel function as a lightweight business automation platform.
